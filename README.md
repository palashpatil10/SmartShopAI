# 🚀 SmartShopAI

### AI-Powered iOS Shopping Assistant (RAG + OpenAI)

SmartShopAI is an intelligent iOS shopping assistant that uses **Generative AI + Retrieval-Augmented Generation (RAG)** to deliver a conversational and personalized shopping experience.

Instead of traditional keyword search, it understands **user intent** and provides **accurate, context-aware product recommendations**.

## 🏗️ Architecture

User Query
↓
Context Retrieval
↓
RAG Pipeline
↓
OpenAI Response
↓
Product Recommendations
